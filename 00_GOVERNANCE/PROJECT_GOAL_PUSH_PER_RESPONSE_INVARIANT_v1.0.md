## Purpose

Every substantive project response must move the project measurably toward the final Ghost Hunter goal.

A response that only reports activity, repeats state, or creates work without reducing a material project gap is not considered successful progress.

## FINAL GOAL

Build a globally comprehensive, evidence-backed, AI-native, autonomous Flash Loan / Atomic Liquidity Arbitrage Hunting Ecosystem that can discover, verify, simulate, risk-check, economically evaluate and safely execute profitable opportunities across the reachable universe, then hunt continuously with zero-trust, fail-closed controls.

The economic execution threshold remains:

NET PROFIT AFTER ALL APPLICABLE MEASURABLE COSTS > USD 0.20

## PER-RESPONSE PUSH RULE

For every substantive response:

1. Identify the current unlocked gate and its highest-value unresolved blockers.
2. Choose work that materially reduces at least one blocker toward the final goal.
3. Prefer closing multiple logically related blockers in one bounded macro-cycle.
4. Preserve measurable evidence of what changed: implementation, verification, test, audit, denominator closure, runtime evidence, or gap reduction.
5. Do not substitute documentation/activity for actual gap reduction when implementation or verification can safely proceed.
6. Do not advance a downstream gate merely because work exists. The active gate must satisfy its own exit criteria first.
7. If the highest-value blocker is externally unavailable, use the same response to complete independent safe work that still reduces the gap, such as architecture hardening, adversarial analysis, deterministic tests, denominator reconciliation or machine-runnable observation contracts.
8. Every final response must state the concrete project movement and the next highest-value gap.

## SUCCESS TEST

A substantive response is considered goal-progressing only when at least one of these occurs:

- a material blocker is closed;
- the verified universe/denominator becomes more complete;
- runtime/evidence coverage materially increases;
- a safety, freshness, provenance or fail-closed gap is closed;
- deterministic test/audit coverage materially increases;
- an executable observation path becomes more complete without granting execution authority;
- an unresolved blocker is converted into a precise, machine-checkable boundary with a concrete closure path.

## NO-DRIFT RULE

Do not spend a response on unrelated optimization, cosmetic restructuring or low-value bookkeeping while a higher-value goal blocker can be safely addressed.

When necessary, maintenance may be performed, but it must remain subordinate to project integrity and goal progress.
