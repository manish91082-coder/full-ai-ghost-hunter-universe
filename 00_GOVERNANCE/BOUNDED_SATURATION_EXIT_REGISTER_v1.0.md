## Purpose
Provide an explicit exit-control record so the project neither exits a gate too early nor remains trapped in an endless saturation loop.

## Gate protocol
For each active gate, maintain:
- mandatory evidence obligations;
- denominator/search scope;
- material gap queue;
- bounded additional discovery cycle count;
- marginal-yield observation;
- adversarial audit state;
- exit decision;
- re-entry triggers.

## Decision states
- CONTINUE_TARGETED_CYCLE: material gap remains.
- EXIT_REVIEW: mandatory work is closed and marginal discovery is being evaluated.
- FREEZE_AND_ADVANCE: exit criteria pass.
- CARRY_FORWARD_UNKNOWN: non-critical uncertainty is explicit and downstream impact is controlled.
- REOPEN_DELTA: a defined re-entry trigger occurs after freeze.
