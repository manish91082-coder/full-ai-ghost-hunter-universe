# 🕵️ FULL AI GHOST HUNTER UNIVERSE

**AI-native, fully automated, goal-centric flash-loan trading research and execution system.**

> **Language policy:** Project documentation and operating logs are maintained primarily in **Hindi**. Technical identifiers, code, protocol names, addresses, hashes, and standards remain in their canonical form.

## 🎯 Core Mission

इस repository का लक्ष्य एक ऐसा **fully AI-based, autonomous, lightweight, zero-cost-first flash-loan hunting system** बनाना है जो उन blockchain ecosystems पर काम कर सके जहाँ flash loans और on-chain arbitrage/trading संभव हों।

System का अंतिम operating objective:

- supported blockchain universe को systematically identify और verify करना;
- हर eligible chain पर flash-loan venues, DEXs, pools, pairs, token addresses, routers, factories, oracles और अन्य static/on-chain metadata का verified knowledge base बनाना;
- known और novel trading/arbitrage strategy space को research, generate, validate और continuously expand करना;
- execution से पहले profitability, liquidity, slippage, fees, gas, revert/failure risk और transaction-level constraints को simulate/verify करना;
- केवल तभी live transaction की अनुमति देना जब configured profitability/risk gates pass हों;
- **net profit threshold: $0.20 से अधिक**, सभी measured execution expenses घटाने के बाद;
- failed/reverting/unprofitable execution को रोकना;
- evidence, provenance, reproducibility और zero-trust validation को architecture का मूल नियम रखना;
- live hunting cycle को कम-से-कम minute-level cadence तक ले जाना, subject to network/provider/execution constraints;
- शुरुआत में **zero-cost infrastructure / free-tier-first** approach अपनाना और system को lightweight रखना।

## 🔐 Non-Negotiable Principles

- **Evidence First:** महत्वपूर्ण तथ्य बिना evidence/provenance के production truth नहीं माने जाएँगे।
- **Verification First:** addresses, contracts, protocol capabilities, liquidity assumptions और execution paths को independently verify किया जाएगा।
- **No Fake Data:** unknown को unknown ही रखा जाएगा; अनुमान को verified fact नहीं बनाया जाएगा।
- **Fail Closed:** uncertainty, revert risk, stale data, insufficient liquidity या negative economics पर trade नहीं।
- **Goal-Centric:** हर engineering/research decision final hunting goal के विरुद्ध evaluate होगा।
- **Zero-Trust:** कोई provider, RPC, model, venue, quote, route या data source automatically trusted नहीं।
- **Zero-Cost-First:** free/public/open infrastructure को प्राथमिकता; paid infrastructure तभी जब justified और explicitly controlled हो।
- **Lightweight:** unnecessary infrastructure, duplicated data और wasteful polling से बचना।
- **No Live Money Until Ready:** research और simulation maturity से पहले live capital का उपयोग नहीं।
